# Agent instructions

The rules for this repository live in [`CLAUDE.md`](CLAUDE.md). Read that file
before making changes. It is the single source of truth for architecture, AI,
data isolation, security, and process rules.

Supporting documentation:

- [`docs/README.md`](docs/README.md) — stack, setup, how to run the app, tests,
  and asset builds.
- [`docs/architecture-decisions.md`](docs/architecture-decisions.md) — the ADRs
  and the reasoning behind them.

> This file replaces the Laravel skeleton's default `AGENTS.md`, which bootstrapped
> the Laravel Boost package. Boost is not installed: adding a dependency is a
> decision to be made deliberately (see `CLAUDE.md`, Architecture rule 12), not a
> scaffolding default.
